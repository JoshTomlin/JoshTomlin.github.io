In Development Bridge Lab C++ · WebAssembly · JavaScript A bridge declarer-play tool that searches for one policy across possible defender hands.

Bridge Lab takes the visible North and South hands and constraints on the defenders. It counts and samples legal hidden deals, then uses αμ search to find one declarer policy across those possible worlds. Declarer must play the same card in deals that are still indistinguishable, but the policy can change after a defender reveals new information.

AlphaMu2 starts with a larger pool of deals, selects a smaller varied set, tests the fixed policy on held-out makeable layouts and adds distinct failures to the next search. The C++20 engine uses DDS for exact leaf values and compiles to WebAssembly. The JavaScript site provides deal entry, constraints, interactive play, simulation and reports explaining each decision.

In Development JBLD JavaScript · React · PWA A local-first timer that reconstructs and analyses blindfolded Rubik’s Cube solves from smart-cube moves.

JBLD connects to supported Bluetooth smart cubes and records the scramble, solve moves and timestamps. It replays the solve, identifies cycles, parity, flips, twists and cycle breaks, and converts the result to the user’s letter scheme and buffers. It shows recognition and execution time for each case and can build a recommended memo and solution.

The React PWA stores sessions, solves, commutators and the user’s algorithm library in the browser. It also provides practice, review, history, statistics, import and export. Its core timer, parser, library and history work offline after the app has been cached; no remote server or sync service is used.

In Development Love Letter TypeScript · React A playable two-player browser game with a bot that estimates hidden cards and explains its decisions.

Love Letter is a complete two-player browser game. Its bot receives only the information available to a real player: its own hand, public discards and actions, cards revealed to it, and the number of cards left. It keeps a probability range for the opponent’s hand, updates that range from public choices and scores each legal action against it.

The bot can also test actions across sampled hidden deals and mix between close choices. The Bot brain panel shows its current range, evidence, action scores, strategy probabilities, sample count and decision time. The deterministic TypeScript engine contains the classic rules and scoring, while gameplay and analysis run entirely in the browser with no backend. The strategy uses ideas from imperfect-information game solving, but it is not claimed to be game-theory optimal.

Android Apps

2024 Personal Connections Godot · Android A personalised word-grouping puzzle game based on The New York Times game Connections.

Personal Connections is a custom puzzle game based on Connections from The New York Times. Each level asks the player to sort sixteen words into four related categories, with four mistakes allowed. I made the app for my wife’s birthday, with sixteen themed puzzles based on the people, places and interests we share.

The levels are connected by another layer of clues that gradually becomes visible as they are completed. Progress is saved locally on the device. The app was built in Godot for Android.

2024 500 Scorer Godot · Android A scoring companion for the card game 500.

500 Scorer records player names, the dealer, the contract, the declarer and the number of tricks made. It calculates scores for standard contracts, Misère and Open Misère, and keeps both the current game score and the match score.

The current game is saved locally so scoring can continue after the app is closed. The app was built in Godot for Android.
