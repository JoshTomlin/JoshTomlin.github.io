In Development Bridge Lab C++ · WebAssembly · JavaScript An imperfect-information declarer-play solver that searches across possible defender layouts without strategy fusion.

Bridge Lab samples defender layouts compatible with the known cards and user-supplied constraints, then applies an optimised αμ search over those worlds. Unlike pure double-dummy Monte Carlo analysis, it retains a single contingent declarer strategy across possible layouts, reducing strategy fusion. I am also developing probability-weighted sampling, adversarial layouts and remembered counterexamples to improve which hidden layouts are tested.

The computational engine is written in C++ and compiled to WebAssembly with Emscripten. A JavaScript interface handles deal entry, constraints, visualisation and locally stored analysis history.

In Development JBLD JavaScript · React · PWA A training timer and solve-analysis tool for blindfolded Rubik’s Cube solving, with a focus on 3-Style.

JBLD records solves, connects to supported Bluetooth smart cubes and reconstructs blindfolded solutions into commutators. It reports move counts, letter pairs, algorithm timings, memo and execution time, pauses and execution mistakes. It supports 3-Style, M2, Old Pochmann and Orozco, with configurable buffers, letter schemes and cube orientations.

The React progressive web app is designed for mobile use, works offline and stores solve and session history locally. Optional Supabase sync can merge that history across devices.

In Development Love Letter TypeScript · React A browser implementation of Love Letter designed for human-versus-bot play.

The TypeScript and React application separates a deterministic rules engine, bot strategies and the user interface. Bots receive only each player’s visible information rather than the full hidden game state; the interface submits player actions and renders engine events.

The project is being developed towards complete classic-card rules, round scoring, two-player setup and playable human-versus-bot games. Automated tests cover the engine and interface.
